    LC 51

    A diagonal in one number

    Walk down a ↘ diagonal and the row and the column both go up by one, so row - col never changes. Walk down a ↙ diagonal and the row goes up while the column goes down, so row + col never changes. Turn on Diagonal numbers: every square shows its ↘ number in the top corner and its ↙ number in the bottom one, and each diagonal is one repeated number.

    row + col already runs from 0 to 2n − 2. row - col runs from −(n − 1) to n − 1, and adding n - 1 shifts it to 0 … 2n − 2 so it can index an array. That's why both diagonal arrays have 2n − 1 slots.

    Where the time goes

    Turn off Stop at blocked squares to see only the placements and removals. Most of the work is in squares turned down on the spot. The counter keeps going either way: for n = 6 the search makes 153 calls and checks 894 squares (6 for each of the 149 calls that aren't a full board) to find 4 boards. Without the arrays every one of those checks would walk back up the column and both diagonals, which is what the unused valid() in the solution does.

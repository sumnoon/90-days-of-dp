    include / exclude

    Two trees, same subsets

    Include / exclude asks one yes-or-no question per level: is nums[start] in? Every element doubles the paths, so there are 2n leaves, and a subset is only recorded at a leaf, once every element has been decided. The tree has 2n+1 − 1 calls.

    For loop from start asks a different question: which element comes next? Every box is already a subset, so it is recorded as soon as the call starts, and the tree has exactly 2n calls. Recursing with i + 1 means only later elements can follow, which is why [2, 1] never appears. LC 77, 39, 40 and 90 all reuse this shape.

    Whatever a call pushes, it pops before it returns.

    Why the pop

    cur is passed by reference, so every call writes into the same vector, as ans did in Week 2's traversals. After exploring the branch with an element, the next branch must not still contain it. pop_back undoes the choice, and the strip shows cur back where it was before the push. Leave it out and leftovers from one branch leak into every branch after it.
